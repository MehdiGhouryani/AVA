# راهنمای دارایی‌های بازبینی

این پوشه فقط برای مقایسه و نگهداری دارایی‌هایی است که هنوز مصرف نهایی آن‌ها در محصول تأیید نشده است.

- `screenshots/`: تصاویر کامل صفحات؛ برای مرجع دیداری، نه برای قراردادن مستقیم در UI.
- `candidates/page2-1/`: دارایی‌های استخراج‌شده از مجموعهٔ منبع Page2-1.
- `candidates/page2-2/`: دارایی‌های استخراج‌شده از مجموعهٔ منبع Pagr2-2؛ نام پوشهٔ غلط تایپی اصلاح شده است.
- `candidates/s03a-login/`: پس‌زمینه و تزئینات کاندید مرتبط با صفحهٔ ورود S03a.
- `alternates/`: نسخه‌های جایگزین برای مقایسه.

وجود فایل در این پوشه به معنای تأیید هنری، تخصیص نهایی به صفحه یا ثبت صحیح در manifest نیست.
