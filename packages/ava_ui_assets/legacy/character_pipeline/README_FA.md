# خط لولهٔ شخصیت قدیمی — فقط بایگانی

**این پوشه بخشی از مسیر اجرایی/منبع حقیقت فعلی نیست؛ اسکریپت‌ها و کد Dart آن را از روی ساختار قبلی شخصیت‌ها نگه داشته‌ایم تا تاریخچه و منطق احتمالی از دست نرود. آن‌ها را اجرا یا مستقیماً وارد اپ نکنید.**

## چرا بایگانی شد؟

- اسکریپت قدیمی انتظار `assets/characters/ava/body/`, `ava/head/` و `friends/<id>/` را دارد؛ دارایی‌های فعلی در مسیرهایی مانند `assets/characters/ava/`, `assets/characters/Roka/` و `assets/characters/Fandogh/` قرار دارند.
- `metadata/characters.json` متعلق به مدل قدیمی (از جمله `friends: []` و فهرست‌های نقش/zone) است و تأیید نهایی نقش شخصیت‌های فعلی محسوب نمی‌شود.
- این خط لوله manifestای به نام `assets/characters/manifest.json` می‌خواند/می‌سازد. Manifest فعال فعلی در ریشهٔ بسته یعنی `../manifest.json`، رجیستری صفحه‌محور با schema متفاوت است.
- کد Dart و تست آن در یک package Flutter مستقل با `pubspec.yaml` اجرا نشده‌اند؛ تست از نام نمونهٔ `your_app` استفاده می‌کند.
- جست‌وجوی import نشان داد نمونهٔ React، اپ موبایل و بک‌اند فعلی از این کد استفاده نمی‌کنند؛ تنها prompt فاز شخصیت‌ها به آن ارجاع می‌داد که اصلاح شده است.

## شرایط بازیابی یا حذف نهایی

فقط پس از تصمیم مالک دربارهٔ نقش Ava/Roka/Fandogh و طراحی قرارداد شخصیت‌ها، این کدها را با schema و فایل‌های واقعی تطبیق دهید. اگر مهاجرت انجام نمی‌شود، حذف کامل این پوشه در یک commit مستقل ممکن است؛ فعلاً برای ممیزی و traceability حفظ شده است.
