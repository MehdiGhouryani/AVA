# دروازه باز QA دستگاه و انتشار
این چک‌لیست علامت موفقیت از قبل ندارد. نتایج با نام دستگاه، Android، نسخه APK و تاریخ ثبت شوند.

- [ ] نصب/اجرای سرد و گرم، بازگشت از پس‌زمینه و چرخش؛ بدون crash یا گم‌شدن پیشرفت.
- [ ] شماره/OTP با IME واقعی، paste فارسی/عربی، فوکوس، Back، Autofill واقعی و خطا/انقضا/قفل.
- [ ] خوانایی همه صفحه‌ها در عرض‌های ۳۲۰ تا ۴۱۲، فونت ۱٫۳ و اندازه بزرگ‌تر، safe insets و keyboard.
- [ ] TalkBack: ترتیب RTL، برچسب، انتخاب، خطای ورودی، کنترل‌های دیالوگ و تمرین؛ هدف لمس ۴۸dp.
- [ ] صدای فارسی آفلاین در دستگاه با voice و بدون voice؛ تلفظ نشانه/کلمه با متخصص، stop و تغییر صفحه/پس‌زمینه.
- [ ] تکمیل همه درس‌ها/قصه‌ها، replay، مرور، پایان همه محتوا و reset/خروج تأییدی؛ بازخوانی پس از بستن برنامه.
- [ ] startup و frame timing/jank با build release روی دستگاه ضعیف و معمولی؛ بدون عددسازی.
- [ ] تأیید آموزش و تناسب سنی، محتوای صوتی، حقوقی/حریم خصوصی و سرویس واقعی حساب.
- [ ] نسخه هدف API و dependency، shrink/release/signing و بسته فروشگاه؛ کلید داخل سورس قرار نگیرد.

ورود mock و محتوای کوتاه توسعه مجازند و نقص سرویس واقعی در این فاز نیستند؛ نسخه انتشار باید رفتار و متن نهایی خود را داشته باشد.
