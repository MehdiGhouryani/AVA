# وضعیت واقعی AVA — سورس ۰٫۴٫۰

این برش موتور یادگیری را از تطبیق دیداری یکسان به سه فعالیت کوتاه گسترش می‌دهد، بدون افزودن صفحهٔ ناوبری یا ادعای برنامهٔ درسی تأییدشده. دامنه همچنان ۴ درس/۱۲ فعالیت و ۲ قصه/۹ صفحه است؛ ترکیب فعالیت‌ها اکنون ۵ تشخیص دیداری، ۴ شنیدن اختیاری و ۳ ساخت کلمه است. `approvedForRelease=false` حفظ شده است.

## تغییرهای این مرحله

- قرارداد محتوا به نسخهٔ ۲ ارتقا یافت. هر فعالیت `id` و `kind` پایدار دارد و schema مستقل، generator و audit ساختار choices/tokens، یکتایی شناسه و پاسخ معتبر را کنترل می‌کنند.
- تشخیص دیداری ظاهر آشنای AVA را حفظ می‌کند. تمرین شنیداری target را ابتدا پنهان می‌کند، دکمهٔ TTS آفلاین دارد و همیشه hint نوشتاری در دسترس می‌گذارد؛ خاموشی narration یا نبود voice مسیر را قفل نمی‌کند.
- ساخت کلمه با tokenهای لمسی، سینی پاسخ، state معنایی و undo پیاده شد. drag اجباری وجود ندارد، token ناقص قابل بررسی نیست و پاسخ غلط بدون از دست‌دادن پیشرفت اصلاح می‌شود.
- صفحهٔ معرفی درس، نوع و شمار فعالیت‌ها را پیش از شروع نشان می‌دهد. progress، feedback و footer میان سه renderer مشترک‌اند تا رفتار بررسی/ادامه یکسان بماند.
- reducer خالص اکنون انتخاب گزینه، انتخاب/حذف token، hint، پاسخ ساخته‌شده، امکان بررسی و گذار بعد را مدیریت می‌کند. ViewModel فقط actionها و ذخیره را هماهنگ می‌کند.
- کلید تازهٔ اشتباه‌ها `lesson:taskId` است. کلید عددی نسخه‌های قبلی همچنان resolve و به ترتیب catalog مرور می‌شود؛ پس از اصلاح، هر دو alias حذف می‌شوند.
- مهارت پروژهٔ `ava-duolingo-learning` با قواعد تنوع درون درس، fallback نوشتاری، tap+undo، هدف ۴۸dp و مهاجرت شناسه به‌روز و lock آن تازه شد.

## مبنای پژوهش و طراحی

مسیر رسمی دولینگو، فعالیت‌های کوتاه را در قدم هدایت‌شده و همراه مرور نگه می‌دارد؛ پژوهش خواندن و Duolingo ABC نیز تنوع تمرین، narration و اجزای ماژولار را توضیح می‌دهند. AVA از این منطق برای تنوع درون همان درس استفاده می‌کند و XP، streak، life یا leaderboard اضافه نمی‌کند. UI UX Pro Max برای target لمسی، feedback و wrap به‌کار رفت؛ Claymorphism به کارت‌های روشن گرد با خط و سایهٔ کم محدود ماند. جزئیات و منابع اولیه در `RESEARCH_FA.md` ثبت شده‌اند.

## شواهد همین سورس

کنترل منابع و ممیزی پروژه موفق‌اند: ۱۶ art، ۲۵۸ متن، فونت، palette، schema v2، ۴ درس، ۱۲ فعالیت، ۲ قصه، سه skill hash و ۱۳ مرجع طراحی. JSONها و اسکریپت‌های Python نیز parse/compile شدند و `git diff --check` بدون خطاست.

برای تغییرهای جدید، ۲ آزمون reducer/model، ۱ آزمون ViewModel و دو سناریوی Compose به‌روزشده نوشته شد؛ مجموع سورس آزمون ۸۱ مورد است. اجرای `testDebugUnitTest` در محیط تازهٔ این نوبت آغاز شد، اما پیش از پیکربندی پروژه متوقف شد چون cache ابزار بازیابی‌شده موجود نبود و شبکهٔ executor به `services.gradle.org` دسترسی نداشت. بنابراین نتیجهٔ ۷۸ آزمون نسخهٔ ۰٫۳٫۶ به این برش نسبت داده نمی‌شود و ۸۱ آزمون تازه هنوز نتیجهٔ اجرایی ندارند. APK/AAB ساخته نشد.

## موارد باز و گام بعد

گام بعد، اجرای همین ۸۱ آزمون و رندرهای فعالیت شنیداری/ساخت کلمه در محیط دارای Gradle/SDK است، سپس QA گوشی برای TalkBack، TTS فارسی، فونت بزرگ، lifecycle و jank. پس از آن باید محتوا و تلفظ با متخصص سوادآموزی فارسی بررسی شود؛ افزایش تعداد درس پیش از این بازبینی، کیفیت آموزشی را ثابت نمی‌کند.

نسخهٔ بعدی سورس می‌تواند موتور جلسهٔ مرور ترکیبی را بر پایهٔ شناسه‌های پایدار توسعه دهد و برای فعالیت‌های تأییدشده فایل صوتی محلی نسخه‌دار اضافه کند. حساب/SMS واقعی، حقوقی، امضای انتشار و سیاست فروشگاه همچنان فازهای مستقل‌اند.
