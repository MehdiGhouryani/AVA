# آرشیو پروتوتایپ اولیهٔ وب AVA

این پوشه اسناد جریان اولیهٔ Google AI Studio / React را نگه می‌دارد. این اسناد برای تاریخچه و بازیابی تصمیم‌ها حفظ شده‌اند؛ **مرجع توسعهٔ جاری نیستند** و دستورهایشان بر قرارداد Native Android تقدم ندارند.

| فایل | کاربرد تاریخی |
|---|---|
| `README_FA.md` | راهنمای اولیهٔ ورود به Google AI Studio |
| `DESIGN_BRIEF.md` | مشخصات اولیهٔ React و تجربهٔ چهار/شش صفحهٔ نخست |
| `PROMPT_01.md` | prompt اولیهٔ ساخت پروتوتایپ وب |

منابع مشترک `design/`، `public/` و `reference/` در ریشهٔ مخزن باقی مانده‌اند؛ این پوشه کپی جداگانه‌ای از آن‌ها نیست.

مسیر محصول فعلی: [راهنمای توسعهٔ AVA](../../README.md) · [فهرست اسناد جاری](../../README.md)
