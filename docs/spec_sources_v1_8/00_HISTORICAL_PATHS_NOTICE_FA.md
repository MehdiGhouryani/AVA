# هشدار: مسیرهای داخل منابع v1.8 تاریخی‌اند

این پوشه برای حفظ اسناد منبع نسخهٔ 1.8 نگه‌داری شده است. بدنهٔ اسناد این پوشه نباید صرفاً برای تطبیق با ساختار جدید بازنویسی یا حذف شود.

در این منابع، مسیرهایی مانند `canonical/`, `prototype_source/`, `baseline_data/`, `design_handoff/`, `archive/` و `character_assets/` متعلق به snapshot قبلی‌اند؛ این پوشه‌ها در ساختار فعلی لزوماً وجود ندارند. این ارجاع‌ها را برای فهم تاریخچه بخوانید، اما آن‌ها را به‌عنوان مسیرهای فعال سیستم‌فایل یا فرمان اجرایی استفاده نکنید.

## مسیرهای فعلی مهم

- رجیستری منبع prototype: `data/screens_v18.json`
- خروجی generated prototype: `prototypes/ux_react/src/generated/screens.json`
- قراردادهای state: `data/state_contracts_v18.json`
- baseline آموزشی: `data/baseline/b/`
- مستندات ساختار فعلی: `docs/PROJECT_STRUCTURE_FA.md`

نسخهٔ v1.8 شامل برخی متن‌ها و recordهای قدیمی ورود ایمیل/Google نیز هست. هدف ورود اپ، شماره تلفن + OTP است؛ ایمیل نباید روش احراز هویت شود. برای تغییرات، مشخصات جاری/owner instruction را معیار قرار دهید و source تاریخی را دست‌نخورده نگه دارید.


حتی عبارت‌هایی مانند «current baseline»، «منبع حقیقت» یا «تصمیم حفظ‌شده» در این مجموعه، وضعیت همان snapshot قدیمی را توصیف می‌کنند؛ این واژه‌ها به‌تنهایی تصمیم جاری را ثابت نمی‌کنند. تمام اختلاف‌های مهم، مخصوصاً auth و نقش شخصیت‌ها، باید با دستور مالک و منابع فعال مقایسه شوند.
