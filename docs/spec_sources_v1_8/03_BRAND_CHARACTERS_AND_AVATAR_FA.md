# ۰۳: برند، همراه محصول و شخصیت‌ها

## وضعیت فعلی
artworkهای قدیمی UI و شخصیت (PNG/SVGهای برند، companion/friend/avatar، screenshotها، boardها و gallery) همچنان از package حذف‌اند و مرجع نیستند. سه character sheet (پوفی، فندق، روکا) به‌عنوان مرجع طراحی در `design_handoff/characters/` هستند و برای هرکدام master لایه‌بندی‌شده و stateهای SVG ساخته شده (پیش‌نویس، تأییدنشده)؛ Lottie و تأیید صاحب محصول و آزمون کودک هنوز انجام نشده است.

## حذف آوا و دانا (تصمیم صاحب محصول)
طراحی آوا (شامل SVG و شش کاندیدای تخت) و دانا (هدهد) تأیید نشد و هر دو **فعلاً از package حذف شدند** (sheet مرجع، assetهای SVG/PNG، سازنده‌ها). فایل‌های اصلی در zipهای آپلودشدهٔ خود صاحب محصول هنوز هست. نتیجه:
- **شخصیت اصلی برند و آیکون اپ فعلاً تعیین نشده**؛ باید دوباره طراحی/انتخاب شود (تحقیق دولینگو: `research/` و خلاصهٔ گفتگو؛ سبک تخت و هندسی پیشنهاد شد).
- اصل قبلی «شخصیت اصلی برند داخل مراحل درس نمی‌آید (مثل Duo)» تا انتخاب شخصیت اصلی جدید در انتظار تأیید است.
- حالت `pofi_with_ava` حذف شد چون آوا را درون فایل می‌گذاشت.

## دوستان
نقش‌های مفهومی قدیمی «روباه، جغد و پرنده» هنوز در slotهای prototype (`Art.jsx` و `App.jsx`) و توضیح چند screen در `screens_v18.json` (مثلاً S07، S12-G6، S14، S32) دیده می‌شوند و به شخصیت‌های جدید نگاشت **نشده‌اند**. این نگاشت یک تصمیم باز است: روکا طبق spec حضور دائمی ندارد و فقط در چالش‌ها ظاهر می‌شود، پس نباید جای «دوست روباه» در S07 بنشیند. تا تصمیم، slotهای قدیمی و artwork آن‌ها canon نیستند.

## آواتار فردی
schema مستقل پروفایل حفظ می‌شود، اما preset artworkهای قدیمی حذف شده‌اند. شخصی‌سازی فعلاً قرارداد داده‌ای است تا طراحی تعیین شود.

## سن محصول
مخاطب کل محصول در این مرحله **۴ تا ۷ سال** است. هیچ selector برای رده‌بندی سنی در onboarding یا ساخت پروفایل وجود ندارد. تفاوت احتمالی در سطح محتوا و سختی باید بعداً در curriculum تعریف شود، نه با انتخاب age band در UI.

## گیت طراحی بعدی
character sheetها باید با pilot کودک، متخصص آموزش فارسی، accessibility و قراردادهای state تطبیق داده شوند و صاحب محصول آن‌ها را تأیید کند. هیچ PNG/SVG حذف‌شدهٔ قدیمی baseline بصری نیست.
